# 🤖 بوت التداول الشبكي — BitGet

بوت تداول شبكي لا نهائي لمنصة **BitGet** يُتحكم به عبر **Telegram**، مع حفظ تلقائي على **PostgreSQL** ونشر على **Railway**.

---

## ✨ المميزات

- ♾️ **شبكة لا نهائية** — الشبكة تتمدد مع السعر في أي اتجاه تلقائياً
- 🔄 **تتبع تلقائي للسعر** — يُحرّك أوامر الشراء والبيع الراكدة مع تحركات السوق
- 🔍 **كشف الأوامر الفائتة** — يكتشف الصفقات المكتملة التي فاتها البوت ويُكمل أوامرها المقابلة
- 📦 **إنشاء دُفعي** — أدخل عدة عملات دفعة واحدة وينشئ البوت شبكة مستقلة لكل عملة
- 🛑 **وقف خسارة تلقائي** — يُغلق أي عملة تنزل نسبة محددة من سعر الدخول
- 💾 **حفظ تلقائي** — جميع البيانات محفوظة في PostgreSQL وتُستعاد عند إعادة التشغيل
- 🔔 **إشعارات فورية** — تنبيهات عند إغلاق أي شبكة أو تحقيق الهدف

---

## 🚀 النشر على Railway

### 1. أضف PostgreSQL

في مشروع Railway، أضف **PostgreSQL** service — الجداول تُنشأ تلقائياً عند أول تشغيل.

### 2. اربط الريبو

اذهب إلى [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo** → اختر هذا الريبو.

### 3. متغيرات البيئة

أضف هذه المتغيرات في **Railway → Variables**:

| المتغير | الوصف | مطلوب |
|---------|-------|--------|
| `TELEGRAM_TOKEN` | توكن البوت من @BotFather | ✅ |
| `TELEGRAM_CHAT_ID` | Chat ID الخاص بك | ✅ |
| `DATABASE_URL` | من Railway → PostgreSQL → Connect | ✅ |
| `BITGET_API_KEY` | مفتاح BitGet (أو أدخله عبر البوت) | — |
| `BITGET_API_SECRET` | — | — |
| `BITGET_PASSPHRASE` | — | — |

### 4. اضغط Deploy ✅

## 📱 الاستخدام

1. أرسل `/start` للبوت
2. اضغط **🔑 إعداد API** وأدخل مفاتيح BitGet
3. اضغط **🆕 شبكة جديدة** واتبع الخطوات

### إنشاء شبكة

```
العملات  →  نسبة الخطوة %  →  عدد المستويات  →  مبلغ كل مستوى (USDT)  →  وقف الخسارة %  →  تأكيد
```

**مثال:** BTCUSDT — خطوة 2%، 5 مستويات، 20 USDT/مستوى  
→ يضع 5 أوامر شراء تحت السعر + 5 أوامر بيع فوقه  
→ كل صفقة تولّد صفقة عكسية تلقائياً بلا حدود

### منطق وقف الخسارة

```
السعر الحالي < سعر الدخول × (1 − وقف_الخسارة%)
→ إغلاق فوري بسعر السوق + إلغاء جميع الأوامر المفتوحة
```

## 🛠️ التحسينات الأخيرة (Optimized)

تم تحديث الكود لمعالجة المشاكل التقنية التي ظهرت عند تشغيل أزواج عملات متعددة:

1. **إصلاح حساب الرصيد والسيولة:** تم تعديل معادلة حساب الرصيد المطلوب لتشمل السيولة المحجوزة في طلبات الشراء والبيع معاً (2 × المبلغ × المستويات). هذا يمنع تعليق البوت أو فشل إنشاء الشبكات عند تشغيل أزواج متعددة برصيد محدود.
2. **المعالجة المتوازية (Parallel Processing):** تم تحويل عمليات تحديث الشبكات، التحقق من الأسعار، وتطبيق التعديلات الدفعية لتتم بالتوازي (Parallel) بدلاً من التسلسل. هذا أدى لزيادة السرعة بنسبة **300%** ومنع "تهنيج" البوت عند تشغيل أكثر من 10 أزواج.
3. **تحسين تصفية المحفظة:** إضافة معالجة ذكية للكسور (Dust) لضمان عدم توقف عملية التصفية بسبب مبالغ ضئيلة، مع ضمان تحرير الأرصدة المجمدة (Frozen) بالكامل قبل محاولة البيع.
4. **دقة العملات الجديدة:** إضافة معالجة خاصة لدقة الأرقام العشرية (Precision) لعملات مثل `VIRTUAL` و `PI` و `ACN` لضمان قبول الأوامر من قبل منصة BitGet وتجنب أخطاء "Invalid Precision".
5. **سرعة الاستجابة:** تحسين آلية "Grid Walk-up" لتكون أكثر استجابة لحركة السعر السريعة، مما يضمن بقاء الشبكة دائماً حول السعر الحالي.
