# 🤖 بوت إعادة توازن المحفظة — BitGet

بوت Telegram يدير محفظة استثمارية على **BitGet Spot** ويعيد توازنها تلقائياً حسب الوقت أو نسبة الانحراف.

---

## ✨ المميزات

- 📊 **محفظة متعددة العملات** — حتى 20 عملة بنسب توزيع مخصصة
- ⏰ **إعادة توازن بالوقت** — كل X ساعات
- 📐 **إعادة توازن بالنسبة %** — عند انحراف أي عملة عن نسبتها المستهدفة
- 🔄 **إعادة توازن يدوية** — زر فوري من داخل المحفظة
- 🛑 **إغلاق فردي أو جماعي** — بيع بسعر السوق
- 💾 **حفظ في PostgreSQL** — استعادة تلقائية بعد إعادة التشغيل
- 🔔 **إشعارات Telegram** عند كل عملية توازن

---

## 🚀 النشر على Railway

### 1. أضف PostgreSQL
في مشروع Railway أضف خدمة **PostgreSQL**.

### 2. اربط الريبو
Deploy from GitHub repo.

### 3. متغيرات البيئة

| المتغير | الوصف | مطلوب |
|---------|-------|--------|
| `TELEGRAM_TOKEN` | توكن من @BotFather | ✅ |
| `TELEGRAM_CHAT_ID` | Chat ID الخاص بك | ✅ |
| `DATABASE_URL` | من PostgreSQL service | ✅ |
| `BITGET_API_KEY` | اختياري (يمكن إدخاله من البوت) | — |
| `BITGET_API_SECRET` | — | — |
| `BITGET_PASSPHRASE` | — | — |

### 4. Deploy ✅

## 📱 الاستخدام

1. أرسل `/start`
2. اضغط **⚙️ إعدادات API** وأدخل مفاتيح BitGet (صلاحيات Spot Trade)
3. اضغط **🆕 إنشاء محفظة إعادة توازن**

### تدفق الإنشاء

```
العملات (حتى 20)
  → مبلغ الاستثمار الكلي (USDT)
  → نسب التوزيع (مجموع 100%)
  → طريقة التوازن: وقت أو %
  → تأكيد → شراء فوري
```

**مثال نسب:**
```
BTC=40, ETH=30, SOL=20, XRP=10
```
أو اكتب `متساوي` لتوزيع متساوٍ.
إذا حددت 19 عملة يمكن ترك الأخيرة تأخذ الباقي تلقائياً.
