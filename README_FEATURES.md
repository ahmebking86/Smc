# إضافات الميزات الجديدة — بوت إعادة التوازن

## الميزات المضافة
1. 🗑 حذف عملة محددة (بيعها وإزالتها من المحفظة)
2. ➕ زيادة الاستثمار (إضافة مبلغ USDT وتوزيعه حسب النسب)
3. ➖ تخفيف الاستثمار (بيع جزء من كل العملات بنسبة معينة)
4. 📈 تقرير أفضل أداء (ترتيب العملات حسب الربح/الخسارة)

## الملفات
- `bot/keyboards_additions.py` → انسخ الدوال داخل `bot/keyboards.py`
- `bot/states_additions.py` → أضف الـ states الجديدة في `bot/states.py`
- `bot/handlers_new_features.py` → انسخ الـ handlers داخل `bot/handlers.py`
- `trading/rebalance_engine_additions.py` → انسخ الدوال داخل `trading/rebalance_engine.py`

## خطوات الدمج السريعة
1. افتح كل ملف أصلي على GitHub
2. انسخ الدوال الجديدة في المكان المناسب
3. في `portfolio_actions` استبدل الدالة القديمة بـ `portfolio_actions_v2`
4. سجّل الـ handlers الجديدة في `main.py` أو مكان تسجيل الـ handlers
5. اعمل Redeploy على Railway

## ملاحظات
- حذف العملة يقوم ببيع الكمية الموجودة ثم يزيلها من الـ target allocations ويعيد توزيع النسب.
- زيادة الاستثمار توزع المبلغ الجديد حسب النسب الحالية.
- تخفيف الاستثمار يبيع نسبة مئوية من كل عملة.
- تقرير الأداء يحسب الربح التقريبي من سعر الشراء الأولي.
